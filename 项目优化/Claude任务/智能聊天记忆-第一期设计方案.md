# 智能聊天记忆第一期设计方案：个人偏好记忆

## 1. 目标

第一期的目标是让系统在新建智能聊天和知识库对话后，仍能记住用户**明确、稳定且由用户自己管理**的偏好。

第一期不追求“像人一样记住全部历史”，只解决一个问题：用户不必在每个新会话重复说明回答语言、表达方式和长期技术背景。

用户能得到的效果：

```text
用户设置：默认中文、先给结论再解释、主要开发 LangGraph Agent。

新开智能聊天：自动以中文、先结论后解释的方式回答。
新开知识库对话：同样以中文、偏工程实现的方式解读检索结果。
```

## 2. 用户与使用场景

### 2.1 用户故事

1. 作为用户，我希望一次设置“中文回答”，以后新聊天默认生效。
2. 作为用户，我希望知识库对话也遵循我的表达偏好，但不因偏好而改变文档原文。
3. 作为用户，我希望随时查看系统保存了什么、修改错误内容、彻底删除内容。
4. 作为用户，我希望关闭个人记忆后，系统不再使用这些偏好。
5. 作为用户，我希望某次临时要求覆盖长期偏好，例如默认中文但本次要求英文。

### 2.2 不包含的体验

第一期不提供以下体验：

- 系统自动分析历史对话并写入长期记忆；
- 用户在会话 A 讨论的具体事项自动出现在会话 B；
- 长对话自动摘要；
- 从大量历史聊天中检索相关结论；
- 项目、导师、论文研究专属记忆。

## 3. 核心概念

第一期只有一种长期记忆：**个人偏好记忆**。

```text
范围：仅当前登录用户
共享方式：同一用户的智能聊天与知识库对话均可使用
保存方式：用户手动新增、编辑、启用、停用或删除
```

个人偏好允许的类别：

| 类别 | 含义 | 示例 |
|---|---|---|
| 回答偏好 | 输出语言、长度、表达结构 | 中文；先结论后解释；偏简洁 |
| 技术背景 | 长期且对回答质量有帮助的背景 | Python 开发者；使用 LangGraph |
| 工作偏好 | 稳定的协作习惯 | 改代码前先给方案；优先解释风险 |
| 长期目标 | 用户明确希望助手理解的长期方向 | 正在开发 Agent 平台 |

个人偏好不应用于保存密码、令牌、身份证件、财务、医疗等敏感内容。界面应明确提示用户不要将敏感信息添加为记忆。

## 4. 功能设计

### 4.1 “我的记忆”管理页

在用户设置中新增“我的记忆”入口。

页面内容：

```text
我的记忆                         [个人记忆：开启/关闭]

回答偏好
- 默认回答语言：中文              [编辑] [停用] [删除]
- 回答方式：先给结论，再解释      [编辑] [停用] [删除]

技术背景
- 正在开发 LangGraph Agent        [编辑] [停用] [删除]

[新增一条记忆]
[清空全部个人记忆]
```

新增或编辑时，用户填写：

```text
类别：回答偏好 / 技术背景 / 工作偏好 / 长期目标
内容：自由文本
是否启用：是 / 否
```

保存前显示说明：

> 已启用的个人记忆会用于你的新智能聊天和知识库对话，以改善回答方式。你可以随时修改、停用或删除。

### 4.2 智能聊天中的展示

智能聊天顶部显示轻量状态：

```text
智能聊天 · 已使用个人偏好
```

点击后可查看本次正在使用的偏好列表，例如：

```text
本次回答使用了以下个人偏好：
- 中文回答
- 先给结论，再解释
- 技术背景：LangGraph Agent 开发

[管理我的记忆]
[本次不使用个人偏好]
```

“本次不使用个人偏好”只作用于当前会话，不删除用户保存的偏好。

### 4.3 知识库对话中的展示

知识库对话使用相同入口和提示：

```text
知识库对话 · 已使用个人偏好
```

个人偏好只影响解释方式、语言、回答粒度，不影响：

- 文档检索范围；
- 检索引用；
- 文档原文；
- 知识库权限。

### 4.4 当前消息的覆盖规则

当前消息的明确要求优先于个人偏好。

示例：

```text
个人偏好：默认中文回答
当前消息：这次请用英文给我写一封邮件
结果：本次使用英文，不修改个人偏好。
```

优先级：

```text
平台安全规则
> 当前用户消息
> 当前会话的“本次不使用”选择
> 启用的个人偏好
> 系统默认行为
```

### 4.5 删除、停用与隐私控制

| 用户动作 | 预期结果 |
|---|---|
| 停用一条记忆 | 不再用于新回答，但保留供用户重新启用 |
| 删除一条记忆 | 立即不再使用，列表中消失 |
| 关闭个人记忆 | 当前用户的全部偏好均不再注入回答，不删除数据 |
| 清空全部个人记忆 | 弹出二次确认；确认后全部删除并立即停止使用 |
| 本次不使用 | 仅当前会话忽略个人偏好，其他新会话不受影响 |

## 5. 回答体验规则

系统应把个人偏好作为“辅助上下文”，不得把它当作不可违背的命令。

例如，“回答简洁”不应导致系统省略安全提醒、关键引用或用户明确要求的详细解释。

每次回答最多使用有限数量的启用偏好；若用户保存了很多条，应优先使用：

1. 回答语言；
2. 输出风格；
3. 与当前技术问题明显相关的背景；
4. 其余偏好不必全部呈现给模型。

## 6. 人工验收测试用例

| 编号 | 操作 | 预期结果 |
|---|---|---|
| P1-01 | 新增“默认中文回答”，新建智能聊天并提问 | 回答使用中文 |
| P1-02 | 在同一用户下新建知识库对话并提问 | 回答使用中文，且仍展示正常文档引用 |
| P1-03 | 保存“先给结论再解释”，询问技术问题 | 回答先给简短结论，再给展开解释 |
| P1-04 | 当前偏好为中文，本次要求英文 | 本次使用英文；返回设置页后偏好仍为中文 |
| P1-05 | 在聊天中选择“本次不使用个人偏好” | 当前会话不再受偏好影响；新开会话仍使用偏好 |
| P1-06 | 停用一条偏好后新开聊天 | 已停用偏好不再影响回答；可重新启用 |
| P1-07 | 删除一条偏好后新开聊天 | 删除的偏好不再出现、不再影响回答 |
| P1-08 | 关闭个人记忆总开关 | 所有个人偏好停止生效；重新开启后已保存且启用的偏好恢复生效 |
| P1-09 | 点击清空全部个人记忆并取消确认 | 所有记忆应保持不变 |
| P1-10 | 点击清空全部个人记忆并确认 | 所有记忆消失，后续新会话不使用任何个人偏好 |
| P1-11 | 尝试保存明显敏感信息 | 页面给出敏感信息提醒；不得静默将其写入个人记忆 |
| P1-12 | 用户 A 和用户 B 分别设置不同语言 | 两个用户的新会话只能使用各自的偏好 |

## 7. 第一期开通标准

第一期完成后，用户应能清晰回答：

```text
系统记住了我什么？
这些内容在哪些会话生效？
我如何让它停止记住或停止使用？
```

如果这三个问题无法由界面直接回答，第一期仍不算完成。
